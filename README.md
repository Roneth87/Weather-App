# 🌦️ Weather App

A simple, modern, and responsive Weather Application built using HTML, CSS, and JavaScript. This application allows users to check real-time weather information for different cities around the world.

## 🚀 Live Demo

🔗 **Live Website:**  
https://weather-app-seven-topaz-79.vercel.app

## 📌 About The Project

This Weather App provides real-time weather information in a clean and user-friendly interface. Users can search for a city and view its current weather conditions, temperature, and other weather details.

The project was developed to practice frontend web development and working with weather APIs.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- 🌤️ Show weather conditions
- 💧 Display humidity
- 🌬️ Display wind speed
- ⚡ Real-time weather data

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and API integration
- **Weather API** – Fetching real-time weather data
- **Vercel** – Deployment and hosting



## ⚙️ How It Works

1. Enter a city name into the search bar.
2. The application sends a request to the weather API.
3. The API returns weather data for the selected city.
4. JavaScript processes the response.
5. The application displays the weather information on the screen.
